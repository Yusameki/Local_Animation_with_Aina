# 04 · 后期合成

> 把一堆单镜、字幕卡、配乐拼成一支「像样」的片子。这一步不产生画面，但能决定「精不精致」。

---

## 1. 逐镜「裁头」：去掉开头那口糊帧

⚠️ 老大难：每一镜生成的**开头 0.2～0.4 秒**，常常是受参考图影响的**糊帧 / 多余画面 / 一声杂音**。

- 现象：每个镜头一开始会「闪」一下、或者有一小段多余的声音；
- 解法：**每段开头统一裁掉一点**再拼：
  - 第一镜（片头）多裁一点，约 `0.4s`；
  - 其余各镜约 `0.25s`；
- 裁的时候**连音频一起裁**（用输入 seek 会让音画同步、一起切掉开头），糊帧和杂音就一起没了。

> 裁完记得重编码（见第 4 节码率），别只 `-c copy`，否则切点会花。

---

## 2. 字幕卡（独白卡）

在两个镜头之间插黑底白字的独白卡，是「故事感」的廉价放大器。

做法：

- 纯黑底 + 居中白字，字体用一款有气质的衬线体（我用的思源宋体 / Noto Serif SC，字号大）；
- 每张停留 **约 2 秒**，整帧做 **fade in / out 各 0.5 秒**，切换不突兀；
- 文案：从角色视角写**短句独白**，一句一卡，串起来是一条情绪线（不是旁白讲故事）；
- 片尾可以来一张只有角落小字（片名/「明天见」）的黑卡收尾。

> 别在片头加卡，直接从正片进；字幕卡服务于情绪，别铺太多。

---

## 3. 配乐：精确截取 + 淡入淡出

⚠️ **最坑的一步**：从一首长 BGM 里截「第 N 秒起」的一段，如果操作不对，开头会「啪」一声**爆音**。

### 错误做法（会爆音）

```
ffmpeg -ss 22 -i bgm.mp3 ...   # 用输入 seek 硬切
```

`-ss` 是切在某个包/波形点上，开头从 0 突跳到非零波形 → 爆音。

### 正确做法（推荐）

```
ffmpeg -i video.mp4 -i bgm.mp3 -filter_complex \
  "[1:a]atrim=start=22:duration=<成片时长>,asetpts=PTS-STARTPTS,volume=0.18,\
        afade=t=in:st=0:d=0.5,afade=t=out:st=<结束前2.5s>:d=2.5[bg];\
   [0:a][bg]amix=inputs=2:duration=first:dropout_transition=0:normalize=0[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac <out>.mp4
```

要点：
- **`-i bgm` 完整读入，再在 filter 里 `atrim=start=N`** —— 采样级精确，不爆音；
- 给 BGM 单独加 **开头 0.5s `afade` 淡入**，双保险；
- 结尾 `2.5s` 淡出；
- `volume` 压到很低（约 0.18），BGM 只做底，别盖过对白/环境音；
- `amix ... normalize=0`：别让 amix 自动把音量拉平，保持你设的比例。

---

## 4. 拼接 + 码率

- 统一所有片段的**分辨率、帧率**再拼；
- 拼接：
  - 片段参数完全一致时可用 `-c copy` 快速 concat；
  - 但**裁过头/重编码过的**片段混在一起，建议统一 **`libx264 -crf 18`** 重编码拼——画质肉眼无损、码率约 `5 Mbps` 级别，投稿够用；
- 别一味追求小体积，B 站投稿 1080p 给足码率才清晰。

---

## 5. 抽帧核对（必做）

拼完成片，**每一镜抽一帧拼成核对表**再看一遍：

```bash
ffmpeg -ss <秒> -i final.mp4 -frames:v 1 -y frame_XX.png
```

把每镜一帧贴成一张图，一眼扫过去：
- 有没有哪镜眼睛崩了；
- 字幕卡在不在、位置对不对；
- 是不是漏了某镜；
- 片尾角标在不在。

> 这是最省事的「质检」。别等上传了才发现问题。

---

## 6. 声音：去/留要分清

- 有些镜模型会**自带一段 BGM**（你没要求的），会和你的配乐打架 → 重生成一版**明确写「无配乐、只要环境音 + 对白」**的；
- 有些镜只需要**去掉声音**（静音 aac 轨）再拼；
- 如果音频比画面**慢半拍**：用 `atrim=start=0.5` 把音频往前提前一点对齐。
