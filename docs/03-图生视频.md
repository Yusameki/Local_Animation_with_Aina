# 03 · 图生视频

> 首帧给你「像不像」，视频给你「活不活」。这一步决定成片是「会动的壁纸」还是「动画」。

---

## 1. fl2va：纯首帧驱动

Minimax H3 的 **fl2va** 模式，是**以一张首帧图为锚**，往后生成动态。

- 你只需要给：**一张首帧** + **一段描述（含运镜和对白）** + **时长/尺寸/步数**；
- 模型会以首帧为第一帧，生成后面所有帧；
- **首帧的构图、光、角色，会被整段延续**——所以首帧有多对，片子就有多稳。

常用参数（实测值，按你的机器微调）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| steps | 8（turbo 模式） | 少步出片，快 |
| 时长 | 4～7 秒/镜 | 单镜别太长，长了容易崩 |
| 尺寸 | 1920×1080 / 1728×960 | 16:9 |
| 采样 | 固定，别乱动 | 换 seed 抽卡更划算 |

## 2. ⭐ 提示词怎么写：别用「一句话」

**这是「PPT 感 / Live2D 站桩感」的根源**：只写一句「两个女孩在街上走」，模型只会给你一个**平移的立绘**——表情不动、脚步不动、镜头不动。

要写成**分层的、像分镜脚本**的结构。我用的是这种骨架：

```
整体风格：电影感日本剧场版动画，2D 手绘，16:9，低饱和 X 调，胶片颗粒
场景：<环境、时间、氛围>
角色A（画面左侧，<名>）：<发色/瞳色/服装/气质>
角色B（画面右侧，<名>）：<...>
表演与互动：<表情怎么变、两人怎么对视、动作幅度、呼吸/发丝>
对白（中文，带自然口型）：A 说「……」，B 回「……」
镜头运动：<推/拉/横移/跟拍 + 景别 + 「不要贴脸」+ 「一个连续长镜头、无剪辑」>
光影：<主光方向、色温、明暗>
```

要点：

1. **写死运镜**：缓缓推近 / 平稳后退跟拍 / 轻微横移……哪怕只是「极缓推近一点点」，动感立刻不一样；
2. **写对白，且带口型**：给台词，模型才会做嘴部动作。台词要贴合角色和剧情；
3. **写表情流动**：「说到一半轻轻笑起来」「听到话后偏头浅笑」——光站着不行；
4. **强调幅度小**：「步幅小、不要跑、始终清晰保持脸」——动作一大，脸就糊；
5. **强调「长镜头、无剪辑」**：免得模型自己切镜。

## 3. 常见失败 & 对策

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 人像**站桩**、只有背景动 | prompt 太简单，没写运镜/表演 | 按上面骨架写详细运镜 + 对白 |
| **走路变原地踏步** / 走不起来 | 走路是最难的动态 | 换 seed 多抽；首帧选「真的在迈步」的；接受「轻微走动 + 镜头后退」的折中 |
| **双人走路掉相**（一个人突然不像了） | 双人 + 大动态，模型吃力 | 拆成单人镜、或改成「站定 + 小幅动作」；多抽 |
| **暗环境崩**（比如影院） | 低光 + 冷蓝屏光，细节丢失 | 提高首帧亮度对比；缩短时长；多抽 |
| **手崩**（多指/畸形） | 手部普遍难 | 首帧就挑手好的；运镜避开手部特写 |
| **二采/长片后角色掉相**（越到后面越不像） | 模型长程一致性有限 | 单镜短一点；每镜用各自最好的首帧 |

> 铁律：**多抽 seed**。视频也是概率游戏，同一首帧换 seed 出几条，挑最稳的。

---

## 4. 分镜节奏

- 一支 1 分钟的片子，拆成 **8～12 个 4～7 秒的单镜**，各自用最好的首帧生成；
- 单镜之间用小过渡（字幕卡 / 空镜）衔接，比硬切顺；
- 每镜**抽帧核对**：生成后每 1～2 秒抽一帧，看眼睛、手、有没有崩——别等拼完才发现某镜废了。
