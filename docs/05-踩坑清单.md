# 05 · 踩坑清单

> 这一页是整支片子的「血泪史」。按 **症状 → 根因 → 解法** 排。你遇到的大概率这里都有。

---

## 出图阶段

| 症状 | 根因 | 解法 |
| --- | --- | --- |
| 单人镜出成**双胞胎** | 某个风格 LoRA 偏向群像，单人会「补」出第二个 | 单人用**纯角色 LoRA 的 solo 配方**（去掉会劈人的风格 LoRA）+ `(solo)/(1girl)` 前置 |
| 双人同框**瞳色/服装串味** | 两个角色 LoRA 语义泄漏 | 分段提示词；或区域条件左右分离；或两段式（先锁构图再改细节）；先抽卡试 |
| 眼睛糊/手糊 | 低清直出细节不足 | **hires 二采**（放大 1.5x + denoise 0.45 精修），再裁脸放大核对 |
| 换了 prompt 画风就飘 | 配方被你改动了 | **锁死配方，只换 seed 抽卡**，不改 prompt |
| 角色「不像了」 | **触发词漏写** | 检查每个角色/服装的触发词都带上了；注意「多角色合集 LoRA」触发了哪个 |
| 区域条件接缝处**补人/黄裙路人** | 左右硬切，接缝被模型补内容 | 构图不稳时别用区域条件；改两段式，只在二采阶段纠细节 |

---

## 视频阶段

| 症状 | 根因 | 解法 |
| --- | --- | --- |
| 人像**站桩 / 只有背景动** | prompt 太简单，没写运镜和表演 | 按分镜脚本写详细**运镜 + 对白 + 表情流动** |
| **走路变成原地踏** | 走路动态太难 | 换 seed 多抽；首帧选「真在迈步」的；退而求其次「小幅走动 + 镜头后退」 |
| **双人走路掉相** | 双人 + 大动态吃力 | 拆单人镜 / 改站定小幅动作 / 多种子挑 |
| **暗环境（影院）崩** | 低光细节缺失 | 提首帧亮度对比、缩短时长、多抽 |
| **手崩** | 手部普遍难 | 首帧挑手好的；运镜避开手特写 |
| 越到后面**角色越不像** | 长程一致性有限 | 单镜短一点；每镜用各自最好的首帧 |
| 生成**自带 BGM** | 模型自作主张加配乐 | 重生成时 prompt 明确写「无配乐（non_diegetic_music: 无），只要环境音+对白」 |

---

## 后期阶段

| 症状 | 根因 | 解法 |
| --- | --- | --- |
| 每镜开头**闪一下/糊帧/杂音** | 开头受参考图影响 | 每段**裁头**（片头 0.4s、其余 0.25s），连音频一起裁 |
| 配乐开头「**啪**」一声**爆音** | 用 `-ss` 硬切在波形上 | 改 `atrim=start=N` 精确截 + 开头 `afade` 淡入 |
| 拼完画质变差/切点花 | `-c copy` 拼了重编码过的片段 | 统一 `libx264 -crf 18` 重编码 |
| 音频比画面**慢半拍** | 音画起点没对齐 | `atrim=start=0.5` 把音频提前 |
| 拼完发现某镜废了 | 没做核对 | 成片**每镜抽一帧**拼表核对 |

## 通用 / 工程

| 症状 | 根因 | 解法 |
| --- | --- | --- |
| 出图出视频**抢显存卡死** | 两进程同时吃显存 | **串行**；切引擎要**结束进程**，不是 `/free`（CUDA context 要进程退出才放） |
| 批量脚本**文件找不到** | `/history` 的 filename 不含子目录、带 `_00001_` 后缀 | 用 `(subfolder, filename)` 拼路径，按 `_000` 切掉后缀 |
| 装某个包**卡十几分钟** | pip 在这台机解析大包极慢 | 先想「有没有更简单的等价路线」；本地 whl + `--no-deps`；实在不行换工具 |
| Windows 脚本打印**中文报错中断** | GBK 编码 | 开头 `sys.stdout.reconfigure(encoding="utf-8")` |
| 改配置**不生效** | 文件改了、运行时没读到 | 去运行时那层把值读回来比，别拿配置文件字面串猜 |

---

> 一句话总结：**首帧多抽卡、视频多抽 seed、后期多抽帧核对**。
> 90% 的坑，都是「抽得不够多」或「没核对」。
