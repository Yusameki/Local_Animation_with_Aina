# 02 · 首帧生图

> 首帧是整支片子的地基。**视频会把首帧的优缺点一起放大**——首帧眼睛画错，视频里就一直错。

---

## 1. 「黄金配方」是什么思路

不是找一个万能模型，而是**锁定一套配方，然后靠多跑 seed 抽卡**：

- **基座**定大方向（画风底盘、二次元质感）；
- **风格 LoRA** 低权重叠加（0.5～0.6），定「味道」；
- **角色 LoRA** 权重高一些（约 0.8），定「是谁」；
- 采样固定：`CFG 5.0`、`euler_ancestral`、`28 步`、`1536×864`。

> 一旦这套数值被肉眼确认「画风对了」，就**别再动它**——之后只换 seed 抽卡，人工挑。这样出图风格才稳定。

---

## 2. 多 seed 抽卡

固定配方，**一批换 seed 跑 8～16 张**，然后人眼挑。这是这套流程最核心的「生产力」：

- 单张不满意不要紧，抽卡就是概率游戏；
- 把每批候选拼成一张「挑选表」（带文件名标注），挑起来快很多；
- **不要**为了某一处小瑕疵反复改 prompt——改 prompt 会牵动整体画风，抽卡更划算。

---

## 3. hires 二采（救细节的关键）

低清直接出，眼睛/手经常糊。做法：

```
低清打底(1536×864)
   → Latent 放大 1.5x（bislerp）
   → 二次采样精修（denoise ≈ 0.45，22 步）
   → 2304×1296
```

- 二采能把眼睛、手指、发丝这类细节救回来；
- `denoise` 太高会改动构图、太低救不回来，**0.45 附近是甜点**；
- 每张二采后一定**裁上半脸放大看眼睛**——这是最容易翻车的地方。

---

## 4. 单人 vs 双人：LoRA 会「劈人」

⚠️ **最容易踩的坑**：某些风格 LoRA 在**单人镜**里，会把一个人画成**双胞胎（两个一样的人）**。

- 现象：明明写的是「一个女孩」，出来两个几乎一样的；
- 根因：那个风格 LoRA 本身偏向群像/双人，单人会「补」出第二个；
- 解法：**单人镜用「纯角色 LoRA」的 solo 配方**（去掉会劈人的风格 LoRA），并加 `(solo)`、`(1girl)` 这类前置强化；
- 双人镜再用完整配方。

> 经验：**别指望一套配方通吃单人和双人**。分两套（solo 配方 / duo 配方），画风几乎一致即可。

---

## 5. 双人同框：属性会被「串」

双人同框时，两个角色的**瞳色、服装、发色**会互相污染——A 的蓝眼被染成 B 的眼色，或者服装互换。

原因通常是「角色 LoRA 的语义泄漏」，处理思路：

1. **权重分层**：给各自的角色 LoRA 和触发词都用单独的 `CLIPTextEncode`（分段提示词），再拼接条件；
2. **区域条件**：用 `ConditioningSetAreaPercentage` 把画面左右分开给两个角色（左角色条件只作用左半边）——但注意这招容易在接缝处「补人」或衣服错位，**构图要稳的时候慎用**；
3. **两段式**：先用全图条件把干净构图锁死（第一段），再在二采那段才换区域条件纠眼睛/属性（第二段），这样构图不动、只修细节；
4. **换 seed 抽**：有时候纯抽卡就能抽到眼睛都对的一张，比改结构省事。

> 判断：先抽卡，抽不到再用区域/两段式。不要一上来就上复杂结构。

---

## 6. 触发词管理

每个角色/每套服装对应一组触发词。**本仓库不写具体触发词**，用占位符：

```
<CharacterA_trigger>  +  <A_outfit>
<CharacterB_trigger>  +  <B_outfit>
```

- 触发词写漏了 = 角色直接「掉相」（变得不像）；
- ★有把「多角色合集」打包在一起的 LoRA——它内部含好几个角色，触发词控制出现哪个；这种最容易串味，务必确认你触发的是哪个角色。

---

## 7. 一致性 = 首帧质量

最终能不能用，看首帧上的这几样对不对：

- ✅ 眼睛颜色（最容易翻车，永远单独裁图放大核对）
- ✅ 服装/配饰是不是这个角色的
- ✅ 手（有没有多指/断指）
- ✅ 脸崩没崩

**这四样对了，才拿去图生视频。** 首帧不对，后面全是白工。
