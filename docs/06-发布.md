## 1. 标题：学官方格式最省心

二次元短片投稿，**标题模仿官方的「栏目化」格式**，观众一眼就知道这是什么：

```
《<游戏/作品名>》<类型>：「<作品名>」
```

例如（通用示意，非真实投稿）：

```
《某个二次元游戏》同人动画短片：「明天见」
```

要点：
- 类型写清楚（同人动画短片 / 手书 / PV …），别含糊；
- 作品名加书名号「」更正式；
- 别堆关键词、别标题党——官方感就是清晰。

---

## 2. 简介：四个要素

一段温柔的开场白 + 必要的说明，四块内容别漏：

1. **氛围句 / 剧情引子**：一句话把片子调性立住（可以从字幕卡里挑一句）；
2. **真诚说明**：「第一次做这种作品，角色还原、画面难免有不到位、请包涵」——反而加分、少挨骂；
3. **STAFF / 声明**：
   - 企划名、角色（版权归原作）；
   - **画面由本地部署的 AI 生成（ComfyUI + 本地模型），含 AI 生成内容**；
   - **音乐**：写明曲名 + 出处 + 「同人非商用，版权归原作者」；
4. 可留一句尾巴（下次见 / 期待反馈）。

---

## 3. 标签 & 合规

- 标签 **6～8 个**即可：作品名、主要角色、同人、动画短片、AI 动画、题材标签（治愈/日常…）；
- ✅ **务必勾选「含 AI 生成内容」** 的平台标识——不勾容易被限流甚至下架；
- 分区挑最接近的（动画 → 手书 / 动画短片）。

---

## 4. 封面：仿官方排版

封面决定点击率。用「角色图 + 大字」的官方式排版最稳：

- **底图**：一张氛围最好、角色最清楚的首帧/成片截图（竖横比按平台，B 站是**横版**）；
- **文字**：只留**作品名大字**，其余杂字全删——越干净越高级；
- **字体**：用有气质的**衬线体**（宋体类），比黑体更「电影感」；字要够粗，缩成小缩略图也看得清；
- **颜色**：别用死白硬描边（像贴上去），试**暖白 + 柔和外发光**，让字融进画面；
- **位置**：放画面**空白/低信息区**（天空、地面），别压住角色的脸和关键部位。

### 用代码出封面（PIL）

```python
# 思路，不是完整代码
base   = 底图.resize((1920,1080))
glow   = 文字层.fill(暖金色).高斯模糊(16)   # 外发光
shadow = 文字层.fill(深色).高斯模糊(7).下移  # 柔和投影
main   = 文字层.fill(暖白)                   # 主字
# 叠放顺序：底图 → 投影 → 发光(两层) → 主字
```

- 字体用可变字体时**记得设字重轴**，否则默认会落到最细的 ExtraLight；
- 出完**缩成 420px 缩略图自检**：主标还看得清 = 合格。
